# How the price world was built

Where each price in the game comes from, and why the shared league replays history instead of following live prices.

## Three kinds of prices

| Used for | Source | Can it execute orders? |
| --- | --- | --- |
| Shared league | Real daily open and close prices from a saved Yahoo snapshot, with Bank of Israel USD/ILS | Yes |
| Administrator test games | Prices and USD/ILS generated by the server for 28 days from a chosen date | Yes, only inside that test game |
| Current market and News pages | TradingView widgets, possibly delayed | No, display only |

The app labels the source on every trading screen. A game keeps the dataset it was created with, so changing data always means a new game.

## Shared league: real historical replay

- **Instruments:** 10 TASE listings (LUMI, POLI, MZTF, DSCT, BEZQ, AZRG, ESLT, ICL, TEVA, NICE) and 10 US listings (AAPL, MSFT, AMZN, GOOGL, NVDA, META, JPM, JNJ, KO, SPY).
- **Period:** October 19–November 2, 2026, with the October 16 close as the baseline. That is two full competition weeks plus one extra day for executions: 21 sessions and 420 opening and closing prices.
- **Prices:** daily opens and closes, downloaded once with the yfinance library without dividend adjustment. Yahoo may already adjust its history for splits, but the window has none. TASE quotes in agorot are divided by 100. Each open and close is replayed at the assignment's market hours; there is no intraday path.
- **Calendar:** every TASE listing skipped October 27, a confirmed TASE closure. A missing price stops the import instead of being guessed.
- **Dividends and splits:** the wider October download had dividends for ESLT.TA and JPM. The chosen window has no reported dividends or splits, which is why it starts on October 19.
- **USD/ILS:** Bank of Israel representative rates. A rate for one day becomes usable at 00:00 Israel time on the next day, so no order can use a rate before it was published. An order on Friday in New York therefore uses Thursday's rate.
- **Checks in code:** the importer stops on a missing day, wrong units, a duplicate bar or an unhandled dividend or split ([tests](../server/tests/yahoo-replay.test.ts)), and the server validates the dataset again every time it starts.
- **Storage:** the snapshot (`historical-8c9e717c12d59090`) is private. It is not in Git; Render loads it from a secret file. The API never returns a price from after the current game time, but the real prices can of course be looked up elsewhere.

The Python script that downloaded the prices is described in [tools/README.md](../tools/README.md). `npm run import:yahoo` (from `server`) turns its report, the market calendar and the Bank of Israel history into the dataset file.

## Data rights

Yahoo does not allow automated downloads without permission, so the download is not repeated and the game never calls Yahoo. Whether the saved prices may be shown in a public app is not verified; a real product would use licensed data. Bank of Israel and ECB rates are public reference data.

## Test games with simulated prices

The real data covers only October 19–November 2, 2026. To test other dates, such as the March daylight-saving changes or four full weeks, an administrator starts a test game with **Start a new game → Simulated test prices** and picks any start date (the default is March 1, 2027). The **Choose game date and time** calendar in World controls only moves time inside the current game, so other dates always mean a new game.

- **Period:** 28 calendar days from the chosen date. Every weekday is a trading day at the assignment's hours, in the real time zones with daylight saving. There are no holidays.
- **Prices:** they start from fixed illustrative values (Apple at $243, for example), not real quotes. Each day, every stock moves by a small gap between days (up to ±0.6%), a move of its whole market (±1.2%), a move of its sector (±0.6%) and a move of its own (±1.6%, or ±0.3% for SPY).
- **USD/ILS:** starts at 3.65 and moves up to ±0.4% each weekday. Like the real rate, each day's value becomes usable at 00:00 Israel time on the next day.
- **Repeatable:** the moves come from a random seed saved with the test game, so a server restart rebuilds exactly the same prices.

These games exist only in the administrator's isolated test realm, are labelled "Simulated", and never replace the shared league's data. Because nobody can look these prices up, the same generator could also run a competition without the replay's hindsight problem, at the cost of realism.

The first version of the game used a similar simulated world for October 2026 with real ECB rates (`npm run import:ecb`). That world is still loaded so old games stay readable. Without the ECB file, the server refuses to start unless `ALLOW_SIMULATED_FX=true` is set, and then it labels the rates as simulated.

## Current market and news

The **Current market** and **News** pages embed [TradingView widgets](https://www.tradingview.com/widget/). Their prices are never copied, stored or used for orders. They may be delayed, and TASE prices there are in agorot.

The status panel also shows the latest Bank of Israel USD/ILS rate (`GET /api/reference/fx`, cached on the server for 10 minutes). It is for reference only and never changes a historical execution rate.

## Sources considered for live or current data

Earlier versions had server-side feeds for live Yahoo quotes and Alpha Vantage news. I removed both: Yahoo needs permission and throttled Render's requests, and the free Alpha Vantage key returned "Premium required" for news.

| Source | What the free plan offers | The problem |
| --- | --- | --- |
| Twelve Data | US daily history | Tel Aviv data is paid, and showing data publicly needs extra rights |
| Alpha Vantage | 25 requests a day | Tel Aviv coverage unclear, personal use only, news is paid |
| TASE Data Hub | A basic free product | Opening and closing prices and public display could not be confirmed |
| Finnhub | US quotes | No price history on the free plan, and sharing the data needs approval |
| Financial Modeling Prep | 250 requests a day | Showing data publicly needs a separate paid licence |
| Marketstack, Massive, EODHD | Small free quotas | Too few requests, or personal use only |
| Interactive Brokers | Broker API | Needs a brokerage account and a desktop gateway running |

No source met every need: both markets, open and close history, free without a card, and permission to show the data in a public app. A live feed also cannot serve an accelerated clock: when an administrator jumps to Friday's close, that close has to exist already, before it happens in the real world.
